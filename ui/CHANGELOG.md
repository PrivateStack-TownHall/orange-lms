# Changelog

All notable UI changes are documented here by product version.

## V4 - Delivery and Operations

- Added upload and certificate-management experiences.
- Completed attendance, task-criteria, assessment-result, scoring, and
  history-class pages.
- Added notification, audit-log, user-activity, and report pages.
- Aligned Axios handling with the shared API response contract.
- Added route-level code splitting, stable UI optimizations, and theme fixes.
- Added calendar month, event-detail, and mobile-agenda experiences through
  the `v4-calendar-*` branch line.

## V3 - Assessment Engine

- Added task-submission, attendance, task-criteria, assessment-result,
  scoring, and class-history user flows.

## V2 - Learning Management

- Added classes, meetings, tasks, notes, and materials screens.
- Added task submission and learning-resource workflows.

## V1 - Core System

- Added authentication, role-aware navigation, dashboard layout, and settings.
- Added user, profile, admin, mentor, and mentee management experiences.
